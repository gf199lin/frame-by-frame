# 如何查看本项目（评委阅读指引）

本目录包含一份**可直接运行的本地预览**，不需要安装任何 npm 依赖。

## 方式一：看视频（最省事，推荐）

打开 `03_演示视频/C_framebyframe_Frame by Frame.mp4`（2 分 43 秒，1080p，含字幕）。视频覆盖首页、片库、DeepWorks 平台、Agent 真实运行、产出、品味画像、审美地图七个部分，均为真实录屏。

## 方式二：看说明书截图

`01_项目说明书/` 中的 DOCX 或 PDF 内嵌 11 张平台运行截图（S1–S11），配合正文说明。

## 方式三：本地预览（需要 Node.js 20+）

1. 确认电脑装有 Node.js：命令行执行 `node -v`。
2. 双击 `启动本地预览.cmd`。
3. 浏览器会自动打开 `http://localhost:8123`。若未自动打开，手动访问该地址。
4. 关闭命令行窗口即停止服务。

**能看到的**：完整前端构建产物，与线上部署同一份代码，含视觉系统、版式与登录页。
**看不到的**：片库、画像、审美地图等业务页面需要登录；AI 分析需要服务端与 API 密钥。本预览不含密钥，也不联网调用模型。

## 方式四：从源码运行（开发环境）

```bash
npm ci
cp .env.example .env.local   # 填写 Supabase 与 DeepSeek 配置
npm run dev                  # http://localhost:5173
npm run api                  # 本地网关 http://localhost:8787（可选）
```

详见上一级目录的 `README-启动与复现.md`。

## 说明

- 本预览为静态构建产物，不含 `.env`、服务端密钥或用户数据。
- 前端内置的 Supabase URL 属客户端公开配置（与任何部署到公网的同类前端一致），不含 service_role 密钥。
- 项目仓库在决赛前设为私有，线上地址不对外提供；代码与构建产物均已随本 ZIP 提交。
