# 第三方依赖清单（摘要）

完整版本锁定见 `04_项目源代码/package-lock.json`。

## 运行时

- React 18 / React Router / TypeScript / Vite
- Tailwind CSS
- Supabase JS Client（认证与云端同步；未配置时自动退回本地模式）
- Zustand（状态管理）
- docx / fflate / jszip（文档生成与打包脚本，仅构建期）
- Express（本地 API 网关，仅服务端）

## 字体与素材

- Instrument Serif、Noto Serif SC：Google Fonts（SIL Open Font License）
- 电影海报与剧照：TMDB 公开图片接口，仅用于本地演示与课程作业，不用于商业分发
- 知识库 12 条：项目原创撰写，来源见 `06_知识库材料/SOURCES.md`

## 未包含

- `.env`、`.env.local`、任何 API Key、Supabase service_role、DeepSeek Key
- `node_modules`、构建产物 `dist`
