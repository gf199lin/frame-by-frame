# Frame by Frame 电影审美知识库 · 来源与授权

## 原则

- 本知识库只收录**项目原创摘要**，不复制受版权保护的长篇影评、书籍章节或付费内容。
- 每条摘要都在描述公开的电影理论概念（因果链、景别、声画关系、类型契约等），但表述由本项目重新撰写。
- 条目可以被引用、检索、展示；引用时必须保留 `kb_id`、标题与来源。
- 如后续引入外部语料，必须在 `entries.json` 中逐条登记来源与授权，并单独审查。

## 检索方式

```powershell
node knowledge/scripts/build-index.mjs
node .opencode/skills/cinema-knowledge-retrieval/scripts/retrieve.mjs --query "克制 悲伤 结局" --top 4
```

- 当前使用**确定性关键词/二元组匹配**，不是向量检索。
- 分数只表示关键词重合度，不代表语义相似度；引用前必须阅读完整条目。
- 返回结果包含 `kb_id`、标题、来源、授权、摘要片段与命中词。
